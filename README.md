\# TaskFlow API



A RESTful Task Management API built with Node.js, Express.js, and MongoDB.



\## Features



\- Create tasks

\- Get all tasks

\- Get task by ID

\- Update tasks

\- Delete tasks

\- Centralized error handling

\- Input validation

\- Automated API testing



\## Tech Stack



\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- Jest

\- Supertest

\- dotenv
